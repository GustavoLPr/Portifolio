Portfólio Pessoal em React

Este projeto consiste em um portfólio pessoal desenvolvido em React, com o objetivo de apresentar projetos, habilidades e informações profissionais de forma moderna, responsiva e organizada.

A aplicação foi construída seguindo boas práticas de desenvolvimento front-end, com foco em componentização, reutilização de código e experiência do usuário.

Tecnologias Utilizadas:

React

JavaScript (ES6+)

HTML5

CSS3

Componentes funcionais

Hooks (useState, useEffect)


Funcionalidades:

Página inicial com apresentação pessoal

Seção de projetos com descrição e links

Seção de habilidades técnicas

Layout responsivo para desktop e mobile

Navegação simples e intuitiva

Estrutura baseada em componentes reutilizáveis


Objetivo do Projeto:

Projeto desenvolvido com foco na construção de uma identidade profissional online, servindo como vitrine para projetos acadêmicos e pessoais, além de demonstrar conhecimentos em desenvolvimento web moderno.
